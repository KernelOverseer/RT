run a benchmark to see your score

points = rendered samples per second, in units of 100 kSamples/s. One sample = one anti-aliased primary ray (scene AA applies), so scores are comparable across resolutions for the same scene. Tiles are handed to workers dynamically — the same next-tile scheduling the native RTBench used for its threads.

RTBench (2021) rebuilt on the WebAssembly port: tile grid 32×20, one WASM engine instance per worker, timing from first dispatch to last tile — thread creation is outside the clock and the score is normalized by rendered samples.
